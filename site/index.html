Install in one line

Paste this into a terminal. It downloads the latest release, checks it, and puts Magpie in your apps.

$ curl -fsSL https://raw.githubusercontent.com/ahaan-shah/magpie/main/install.sh | sh
PS> irm https://raw.githubusercontent.com/ahaan-shah/magpie/main/install.ps1 | iex

Works on x86_64 and ARM. Run the same line again to update, or let Magpie update itself.

Run it in PowerShell. Installs for just you, no admin needed.

Rather click? Get the .dmg, setup .exe or tarball from the latest release.
